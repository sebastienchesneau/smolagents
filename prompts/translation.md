# Étape — Traduction en anglais

Objectif : traduire EN ANGLAIS le résumé et les points d'action produits aux
étapes précédentes (langue source : français).

Consignes de traduction :
- Traduction fidèle et naturelle, en anglais professionnel.
- Préserve EXACTEMENT la structure Markdown de chaque document source :
  mêmes niveaux de titres, mêmes puces, même gras.
- Conserve les noms propres (personnes, projet) à l'identique.
- Adapte les conventions locales sans altérer les faits :
  - montants : `1 500 €` -> `€1,500` ;
  - heures : `10 h` -> `10:00 a.m.` ;
  - jours/dates : traduits en anglais (« mardi » -> « Tuesday »).
- Traduis les libellés structurants : « Échéance : » -> « Due date: ».

Titres à utiliser dans les fichiers traduits :
- pour le résumé traduit : `# Meeting Summary` ;
- pour les points d'action traduits : `# Action Items`.

Règle absolue : ne traduis QUE le contenu existant. N'ajoute, ne retire ni ne
reformule aucune information par rapport aux versions françaises.
